# Spam Classifier

Binary text classifier to detect spam messages using TF-IDF + Naive Bayes.

## Results
- **Accuracy: 97%+** on UCI SMS Spam dataset
- Applies Bayes theorem and conditional probability for real-world NLP

## Tech Stack
Python · scikit-learn · pandas · NumPy · TF-IDF · Multinomial Naive Bayes

## Run Locally
```bash
pip install scikit-learn pandas
python spam_classifier.py
```
